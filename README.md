# 山径线索板 · RaceMemoir

山径线索板是一款记录赛事与山野旅程的 Web 数字收藏板。

将真实奖牌装入展示框、照片用大头钉固定、号码布用胶带贴住，把 GPX 轨迹变成路线卡，在无限画布上用红线串联每段记忆。

## 功能

- ✅ 收藏奖牌、照片、号码布、便签与路线卡，支持上传本地照片并纳入完整备份；可选择相纸类型，图片自动铺满，支持框内缩放与位置调整。
- ✅ 上传奖牌照片，本机自动抠图并补全绶带、原图对比与重试；导入 GPX 生成轨迹、里程和海拔曲线。
- ✅ 所有藏品统一侧栏添加与编辑，保存成功、点击背景或关闭按钮自动收起；收藏记录内容同步更新。
- ✅ 自由拖拽、旋转、编辑、复制和删除藏品；奖牌按可见内容居中，奖牌与展示框独立缩放、一键适配。
- ✅ 图钉红线串联记忆，连接随藏品移动与旋转，双击结束连线。
- ✅ 大头钉、胶带、红线共 12 款样式，支持整板或单件替换。
- ✅ 无限画布、自由缩放平移、拖拽到边缘自动平移、全景适应与缩略图导航。
- ✅ 撤销重做、本地自动保存与收藏板命名。
- ✅ 按全部藏品范围自动裁切 PNG 导出（长边最高 4096 像素），完整 JSON 备份和旧版数据迁移。

## 数据与文件

奖牌图片、GPX 与收藏记录存储在当前浏览器的 IndexedDB，画布位置、装饰与红线自动保存在 localStorage。删除画布物件保留原记录；收藏库的回收站可恢复记录。旧奖牌与路线保留为示例，上传真实文件即可替换关联物件。

奖牌支持 PNG、JPG、WebP（20 MB / 2500 万像素以内）；GPX 支持分段轨迹和路线（15 MB / 10 万点以内）。里程与爬升按轨迹点估算，缺少海拔时仅展示轨迹与里程，不加载地图底图。

JSON 备份包含画布、收藏库（含回收站）、原图、抠图结果及 GPX，最大 80 MB。导入后替换当前画布并合入收藏库，导入的记录使用新 ID，不覆盖已有记录。清理浏览器数据前，可通过「分享 → 导出收藏板文件」备份。

自动抠图使用 [IMG.LY background-removal](https://github.com/imgly/background-removal-js)（AGPL-3.0），首次运行从其 CDN 下载模型与运行时，图片在本机处理。模型加载或处理失败可重试，也可取消抠图并保留原图。

上传奖牌时，FP16 模型抠图后会自动根据原图背景色和前景连接关系补全绶带；对背景较单一、绶带与背景有明显色差的照片效果更好。复杂背景无法可靠补全时保留模型结果。已有奖牌可点击「自动抠图（含绶带）」重新处理，查看预览后保存；原图始终保留。「手动微调」作为可选工具用于修边。

## 运行

需要 Node.js 22.18+（推荐 Node.js 24）。

```bash
npm install
npm run dev
```

打开 [http://localhost:5173](http://localhost:5173)。

```bash
npm run build      # TypeScript 检查与生产构建
npm run preview    # 预览生产构建
npm test           # 运行测试
```
