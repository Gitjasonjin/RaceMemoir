# 真实号码布

左侧「添加号码布」可选择模板制作或上传图片，收藏库也提供「上传号码布」。支持 PNG、JPG、WebP，单张不超过 20 MB、2500 万像素；默认按原始比例完整展示，不覆盖原图文字。

电子号码布可直接保存；实物照片可在「裁切 / 四角校正」中拖动四角去掉外围背景、校正透视。四角依次为左上、右上、右下、左下，也可用方向键微调。应用后先预览，点击保存才写入收藏记录；「恢复原图」可撤回图片处理。展示尺寸等比例调整，胶带、图钉与红线沿用现有交互。

「姓名抹除」由用户在原图上框选区域，不使用 OCR。自动匹配周围底色，可手动取色或选色，支持多区域、撤销及删除。区域以原图归一化坐标保存，裁切与透视校正会同步应用覆盖。画布与 PNG 展示处理结果；原图和 ZIP 完整备份仍保留未抹除的源文件。「恢复原图」同时清除校正与抹除。号码布编辑不提供备注输入，旧记录备注保留以兼容已有备份。

`BibRecord` 在 IndexedDB 保存原始文件、处理图、原始及输出尺寸、归一化四角和处理方式。每次处理都从原始文件采样，以 PNG 保存结果，不通过低清预览图生成。画布通过 `recordId` 引用记录；同一收藏在画布上的多份实例共享图片，各自保留位置、尺寸和装饰。图片比例变化时更新关联实例高度并保持中心位置。

ZIP v6 将两份图片作为独立附件保存，JSON 只保存元数据和引用，导入时重映射记录 ID。继续读取 ZIP v3–v5 和旧版 JSON；旧模板号码布不自动转为上传记录。号码布暂不参与赛事地图的地点聚合。

实现入口：`src/items/bib/`。几何变换、记录校验、备份和本地存储由单元测试覆盖；上传、校正、原图恢复、复用、回收站、刷新、连线及 ZIP/PNG 导出由浏览器测试覆盖。
