# 排版操作

- 按住 Ctrl + 鼠标左键画框批量选择；底部「对齐与分布」提供六种对齐和水平、垂直等距分布。至少选择两个独立物件或组合可对齐，三个可分布。按旋转后的可见边界计算间距。
- 「组合物件」将当前选择合并成一个组。单击组内任意物件可选中整组，拖动、层级调整和对齐都以整组操作。先「取消组合」再单独编辑成员；不支持嵌套组合。
- 「锁定物件」保护位置和布局，阻止拖动、方向键移动、旋转、删除、层级及排版操作。锁定对象仍可选中，在底部点击「解锁物件」恢复编辑；含锁定成员的批量选择整体受保护。连线仍可连接锁定物件。
- 拖动时与其他物件边缘或中心接近到 6 屏幕像素内，会显示辅助线并吸附。拖动过程中按住 Alt 暂停吸附。
- 层级菜单中的「放到指定物件上方／下方」可直接点击目标定位层级。来源批量物件保持内部顺序，目标为组合时放到整个组合之外；鼠标悬停高亮目标。Alt 单击循环切换重叠目标，再点击或按 Enter 确认，Esc 或点击画布外取消。仅改变层级，不改变位置。
- 在重叠区域按住 Alt 单击，从上到下循环选择物件，避免为了选择底层物件而移动其他藏品。

排版操作进入撤销重做历史并自动保存。分组 ID 和锁定标记是可选字段，旧数据无需迁移；ZIP 备份保留它们。辅助线不会保存或导出。

实现入口：`src/board/layout.ts`（旋转边界、组合、对齐和吸附），`LayoutMenu.tsx`（工具栏），`src/app/App.tsx`（手势与状态协调）。
